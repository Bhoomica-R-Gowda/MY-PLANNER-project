My Planner Website

Welcome to my first main web development project! This is a clean, modern, and interactive web application designed to help 
students organize their academic schedules, track daily goals, and optimize their productivity.

Key Features :

*Task Overview: Dynamic dashboard displaying today's focus area and total metrics.
*Progress Tracking: Live analytical cards tracking completed tasks and active study hours.
*Daily Motivation: A dedicated space featuring rotating inspirational quotes to keep students steady.
*Responsive Structure: Built from scratch with a focus on an accessible, clean, and distraction-free user experience.

Built With :

*HTML5: Clean semantic markup for structure and web accessibility.
*CSS3: Custom styles leveraging Flexbox and CSS Grid for layout management.
*JavaScript: Dynamic DOM manipulation for real-time task updates.

 How to Run This Project Locally

1. Clone or download this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Right-click on `index.html` and select - Open with Live Server
 (or simply double-click `index.html` in your file explorer to open it in any web browser).
